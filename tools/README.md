# Verification

These five scripts are the reason the numbers on the screen can be trusted.

The app runs a neural network in JavaScript that was trained in Python. A model
fed slightly different numbers than it was trained on does not crash. It returns
confident nonsense. So every stage between the microphone and the probability is
checked against the Python original, and each script prints PASS or FAIL.

Run them all with node, from anywhere:

```
node tools/check_resample.js
node tools/check_features.js
node tools/check_model.js
node tools/check_chain.js
node tools/check_classify.js
```

| Script | What it proves | Last measured |
|---|---|---|
| `check_resample.js` | 44.1 kHz phone audio reaches 8 kHz the same way `librosa.load` does | 0.0003 dB mean log-mel error, 0.046 dB worst. The box-average resampler it replaced was 1.17 dB mean and 8.90 dB worst. |
| `check_features.js` | `features.js` reproduces `librosa.feature.melspectrogram` plus `power_to_db` | 1.3e-6 dB mean, 7.6e-6 dB worst, which is float32 rounding |
| `check_model.js` | `model.js` reproduces the Keras forward pass on four random inputs | worst absolute error 1.8e-7 on the output probability |
| `check_chain.js` | the whole path, audio in and probability out, matches Python end to end | worst absolute error 4.1e-8 |
| `check_classify.js` | the aggregation behaves: a tone is detected, noise is not, silence is skipped rather than scored, short input raises an error, 48 kHz works | all five cases |

## What is deliberately not proved here

**How accurate the models are.** These scripts prove the JavaScript computes the
same thing as the Python. They say nothing about whether the Python was any good.
That comes from the held-out scores printed by `train_wingbeat.py`, which belong
in `models/report.json`. Until those are filled in, the app says on screen that
the accuracy has not been recorded, and that is the honest state.

**That the models work on Indian mosquitoes.** They were trained on HumBugDB,
which contains no Indian recordings. Nothing in this folder can establish how
they behave on wild *Culex quinquefasciatus* in Thanjavur. Only labelled local
recordings can, which is what the app's export button exists to collect.

## Fixtures

`test_signal.bin`, `rs_in44k.bin` and the `*_ref*` files were generated by
librosa and Keras in Python. They are the ground truth; do not regenerate them
from the JavaScript, which would make every check circular and meaningless.
